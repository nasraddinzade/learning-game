## Сценарии e2e (`e2e/smoke.spec.ts`)

1. **Лагерь и все экраны.** Открывается Лагерь, счётчики по нулям, нет горизонтальной прокрутки. Кликами по ссылкам открываются Из жизни, Летопись, Зал трофеев, Статистика, Настройки, с каждого возврат кнопкой Назад. Прямыми URL открываются Бой, Встреча, Карта, Усиление, Итог, Привал. Неизвестный путь уводит в Лагерь. За весь сценарий в консоли нет ошибок, предупреждений React и упавших запросов.
2. **Настройки переживают перезагрузку.** Новых в день 6 → 8, звук выключен, голос UK. После `reload` значения те же (IndexedDB).
3. **Офлайн.** Первая загрузка, ожидание активации service worker, перезагрузка, затем `context.setOffline(true)`: Лагерь открывается, переход в Настройки работает, прямая ссылка `/battle` отдаётся из кэша.
4. **Манифест.** `manifest.webmanifest` отдаётся, `display: standalone`, `start_url: /`, есть maskable-иконка 512, все три PNG отдаются с `image/png`.

## Что нельзя проверить без человека

Чек-лист для реального Xiaomi 11 Lite после того, как приложение будет развёрнуто по HTTPS (этап 6) или открыто с компьютера по локальной сети:
- [ ] Chrome предлагает «Добавить на главный экран», иконка и название Nemesis выглядят нормально, запуск без адресной строки.
- [ ] В режиме полёта установленное приложение открывается и переходит между экранами.
- [ ] Тумблеры и кнопки «−/+» в Настройках удобно нажимать одной рукой, ничего не промахивается.
- [ ] Нет горизонтального покачивания страницы при свайпе.
- [ ] Тёмный фон на AMOLED выглядит чёрным, акцентный оранжевый не режет глаза.
- Микрофон, озвучка, вибрация и экранная клавиатура в этом этапе ещё не используются, проверять нечего.
