# Этап 3. Звук и речь. Отчёт самопроверки

Дата: 2026-10-03

## Что сделано

**Речь (`src/speech/`)**
- `tts.ts`: озвучка через `speechSynthesis`, выбор голоса по языку из настроек (en-US / en-GB, локальный предпочтительнее), страховочный таймаут на случай немого движка, `setSpeaker` для подмены в тестах.
- `recognition.ts`: распознавание через `SpeechRecognition` / `webkitSpeechRecognition`, до трёх альтернатив, таймаут прослушивания, `setRecognizer` для подмены. В запрос уходят только учебные фразы.
- `moves/availability.ts`: На слух и Диктант доступны только при озвучке; Голос и Экспромт всегда (Голос без распознавания идёт через самооценку, Экспромт можно напечатать).

**Приёмы (`src/moves/`)**
- На слух (ступень 1): предложение звучит и не показывается, выбор смысла из трёх; две ложные подсказки берутся из предложений других фраз той же земли.
- Диктант (ступень 3): предложение звучит, печатается целиком, переслушать можно один раз, одна опечатка в длинном слове даёт Hard.
- Голос (ступень 4): ситуация по-русски, микрофон, проверка `matchVoice`: фраза найдена в распознанном тексте, либо услышано ≥ 80% её слов (считается опечаткой, Hard). Без распознавания: «Сказал, показать образец» → образец с озвучкой → «Верно / С ошибкой / Не смог».
- Экспромт (ступень 5): ситуация из второй половины списка, которую Перевод не использует, 6 секунд на старт голосом или печатью, тиканье на последних трёх секундах, не начал — промах «(не начал)».
- Озвучка: автоматически в Знакомстве и после ошибки (правильная фраза), кнопка динамика в Знакомстве и в фидбеке, кнопка «Проверить голос» в Настройках со строкой статуса озвучки и распознавания.

**Звук и вибрация (`src/ui/fx.ts`)**: синтез через Web Audio без файлов: удар, крит (плюс вспышка экрана), удар врага, закрытый долг, ступень вверх, победа в бою, большая фанфара для немезиды и Эха, тик и «время вышло» Экспромта. Вибрация через `navigator.vibrate` с паттернами. Оба выключаются в Настройках, выключатели уже были и теперь работают.

**Тесты**: `src/moves/speech.test.ts` (сборка задач На слух с чужими подсказками, Диктант с опечаткой, Голос с альтернативами и порогом 0.8, самооценка, Экспромт с новой ситуацией и пустым ответом, все 303 фразы поддерживают новые приёмы). `e2e/speech.spec.ts` на фальшивой речи: озвучка записывается, микрофон возвращает заданную фразу.

## Сценарии e2e (`e2e/speech.spec.ts`)

1. **На слух.** Принудительный приём через хук: предложение озвучено автоматически и не показано на экране, три варианта, повторное прослушивание добавляет запись в `spoken`, неверный выбор даёт промах, после промаха правильная фраза озвучена и есть кнопка динамика. Консоль чистая.
2. **Диктант.** Текст не показан, одно переслушивание, после него кнопка выключена, ввод предложения даёт удар.
3. **Голос с распознаванием.** Фальшивый микрофон возвращает «well <фраза> i guess» → удар; «something completely different» → удар врага.
4. **Голос без распознавания.** `data-supported=false`, образец по кнопке, «С ошибкой» даёт удар с оценкой Hard.
5. **Экспромт.** Таймер виден, без действий через 6 секунд промах «(не начал)»; во втором Экспромте печать в срок убирает таймер и даёт удар.
6. **Настройки.** Статус «Озвучка: есть», «Проверить» озвучивает образец, выключатели звука и вибрации переживают перезагрузку.

Регресс: `run.spec.ts` и `smoke.spec.ts` на фальшивой речи (`wipeAll` ставит её всегда), автопилот умеет На слух, Диктант, Голос и Экспромт.

## Ручной проход (dev-сервер, встроенный браузер)

Настройки показали настоящий голос Windows (Microsoft Zira, en-US) и наличие распознавания. Поход → Знакомство с кнопкой динамика, консоль без ошибок. Услышать звук из встроенного браузера нельзя, это пункт для телефона.

## Глаза (скриншоты в `screenshots/stage-3/`)

`phone-listen` (большая кнопка «Прослушать», три варианта с номерами, английского текста нет), `phone-dictation` (поле, счётчик оставшихся прослушиваний у динамика), `phone-voice` (большой микрофон «Нажми и говори»), `phone-voice-self` (образец, динамик, «Верно / С ошибкой / Не смог»), `phone-improv` (таймер «6 с», микрофон рядом с полем), `phone-feedback-miss-speak` (динамик у правильного ответа).

Честная оценка: четыре приёма выглядят единообразно с остальными и помещаются в экран. Ряд «Рискнуть» с шестью приёмами на ступени 1 выглядит громоздко (два ряда чипов), стоит показывать только два-три ближайших по ступени, запишу в баланс после живой игры. Звук и вибрацию из встроенного браузера не услышать, это в чек-листе.

Найдено и исправлено по ходу
- `wipeAll` в e2e опирался на перезагрузку из dev-панели и иногда ставил подмену речи в умирающий документ; добавлен хук `wipe()` без перезагрузки.
- Подмена речи слетала после перезагрузки страницы (`shiftDays`), и в Логове настоящий распознаватель headless-браузера зависал на «Слушаю…»; флаг подмены теперь живёт в sessionStorage.
- Принудительный приём для тестов расходовался на Знакомстве; теперь применяется только к настоящему бою.
- Два юнит-теста были написаны неверно (перестановка букв это две правки, а не опечатка; пример для порога 0.8 не дотягивал до порога).
- Ожидание в e2e похода: самый сложный приём Эха теперь Экспромт, а не Перевод.
- Быстрые два тапа по выключателям и мгновенная перезагрузка теряли вторую запись в IndexedDB: тест ждёт подтверждения состояния.
