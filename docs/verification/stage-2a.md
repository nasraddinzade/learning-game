# Шаг 2а. Режим чтения без ИИ. Отчёт самопроверки

Дата: 2026-10-03

Шаг добавлен в план после сдачи этапа 2 (SPEC §9.3, §17), сделан после этапа 4.

## Что сделано

**Данные**
- Таблица `texts` (`TextDoc { id, title, body, createdAt }`) в схеме Dexie версии 2, у `Item` необязательное поле `textId`, у контекста источник `'life'`.
- `src/db/textRepo.ts`: библиотека (`allTexts`, `addText`, `deleteText`, `itemCountsByText`) и `addLifeItem`: фраза с переводом от пользователя, предложение из текста первым контекстом, `source: 'life'`, `land: 'life'`. Удаление текста элементы не трогает.
- Недостающие поля (ситуации, ложные смыслы, другие контексты) остаются пустыми: `canUse` держит такой элемент на приёмах, которым хватает одного контекста (Пропуск, Перевод, Диктант, Голос, плюс Сборка и На слух при озвучке); Свайп и Экспромт ждут ИИ.

**Чистая логика (`src/reading/text.ts`, без React)**
- `parseText` / `tokenize`: абзацы и токены-слова (апострофы и дефисы внутри слова), `titleFor` для библиотеки.
- `selectWord`: тап выбирает слово, второй тап в том же абзаце расширяет до фразы, тап внутри выделения или дальше `balance.reading.maxWords` (8) начинает заново; `dragTo` для протяжки от якоря.
- `sentenceAround`: предложение вокруг выделения (не рвётся на «e.g.»), `selectedPhrase`.
- `indexPhrases` / `findPhrases`: поиск уже существующих фраз в тексте без учёта регистра и пунктуации, длинное совпадение важнее, без наложений.

**Экраны**
- «Из жизни»: четыре входа, работает «Читать», остальные три помечены этапом 5.
- Библиотека (`/read`): вставка текста с необязательным названием, список с датой и числом взятых фраз, удаление в два тапа с подсказкой, что фразы останутся.
- Читалка (`/read/:id`, ленивый чанк): крупный шрифт 19px, только текст. Выделение тапами и протяжкой (протяжка начинается с выделенного слова, поэтому прокрутка страницы не ломается: `touch-action: none` стоит только на выделенных словах). Панель над выделением, прижимается к краям экрана и уходит под выделение, если сверху нет места: «Послушать» (TTS), «Перевод», «В поход». Для фразы, которая уже в игре, вместо «В поход» показан её статус. Шторка «В поход»: фраза, предложение-контекст, поле перевода, Enter добавляет. Шторка «Перевод»: перевод и статус для известной фразы, для новой подсказка про этап 5 и переход к добавлению. Подсветка статусов: новая (акцент), в бою (зелёная), немезида (красная), приручена (серая). Длинный текст рендерится по 30 абзацев по мере прокрутки.

**Тесты**: `src/reading/text.test.ts` (13 тестов), `e2e/reading.spec.ts` (2 сценария).

## Сценарии e2e (`e2e/reading.spec.ts`)

1. **Текст → фразы → поход → удаление.** Вставка текста с названием; слово «risky»: панель, шторка с фразой и предложением «It sounds risky, but let's give it a shot and see what happens.», перевод, подсветка «new», счётчик 1; фраза «give it a shot» двумя тапами (четыре слова); девять слов начинают выделение заново, тап внутри тоже; для «risky» панель показывает статус вместо «В поход», «Перевод» даёт введённый перевод; для новой фразы «Перевод» ведёт к добавлению. Библиотека показывает «фраз взято: 2». В походе первый же узел встречает «risky» Знакомством с этим предложением. После похода подсветка «fight». Удаление текста: библиотека пуста, в IndexedDB по-прежнему две фразы из жизни, старая ссылка показывает «Текста больше нет». Консоль чистая.
2. **Края и перенос строки.** Последнее слово первой визуальной строки и первое слово следующей выделяются вместе, панель целиком внутри окна; первое слово у левого края тоже; протяжка мышью от выделенного слова расширяет фразу до «not sure about this», клик после протяжки не сбрасывает выделение.

## Ручной проход (dev-сервер, встроенный браузер, 393×873)

«Из жизни» → «Читать» → вставил три абзаца, название Chat → читалка: фразы из seed («How have you been», «I didn't catch your name», «Anyway», «let's keep in touch») уже подсвечены статусом; тап «risky» → панель над словом → «В поход» → шторка с предложением → перевод, Enter → тост ««risky» ждёт тебя в ближайшей Разведке», подчёркивание акцентом, счётчик ⚔️ 1; тап «give», тап «shot» → выделены четыре слова, панель 41..385px по ширине 393. Ширина страницы 393 без горизонтального скролла.

## Глаза (скриншоты в `screenshots/stage-2a/`)

`phone-reader` (текст с подсвеченными фразами seed), `phone-word-selected` (панель над словом «risky»), `phone-add-sheet` (шторка с предложением и полем перевода), `phone-phrase-added` («give it a shot» подчёркнута как новая), `phone-translate-known` (перевод и статус известной фразы, панель с «✓ новая»), `phone-library` (карточка текста с датой и «фраз взято: 2»), `phone-intro-from-life` (Знакомство в Разведке: «risky», «рискованно», предложение из текста), `phone-status-after-battle` (зелёные «в бою» и жёлтые новые), `phone-edge-selection` («It» в конце строки и «sounds» в начале следующей, панель внутри экрана), `phone-drag-selection` (протяжка «not sure about this»).

Честная оценка: читалка выглядит как читалка, а не как форма: текст и ничего лишнего, панель появляется там, где палец. Подсветка статусов делает чужой текст «картой уровня». Слабые места: нет поиска по библиотеке и нет позиции прокрутки для возврата к длинному тексту; «Послушать» в панели читает фразу, а не предложение. Записал в идеи для полировки.

## Что нельзя проверить без человека

- [ ] Тап по слову на Xiaomi попадает с первого раза, выделение видно под пальцем, прокрутка не ломается.
- [ ] Протяжка от выделенного слова расширяет фразу, страница при этом не скроллится.
- [ ] Панель не перекрывается системной клавиатурой при открытой шторке перевода.
- [ ] Вставка из буфера обмена длинного текста (статья на 2–3 тысячи слов) не тормозит, прокрутка дорисовывает абзацы.
- [ ] «Послушать» читает фразу выбранным голосом.
