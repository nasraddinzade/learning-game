# Этап 5. ИИ. Отчёт самопроверки

Дата: 2026-10-04

## Что сделано

**Слой ИИ (`src/ai/`, SPEC §10)**
- `types.ts`: интерфейс `AIProvider.complete(request)`, `AIError` с видами auth / rate / network / bad-response, контракты `ProductionCheck`, `SceneTurnResult`, `FreshContext`, `LifeItemDraft`.
- `gemini.ts` (основной, ключ в заголовке `x-goog-api-key`, `responseSchema` в `generationConfig`) и `groq.ts` (запасной, OpenAI-совместимый, `json_object`). Модели берутся из настроек, по умолчанию `gemini-2.5-flash` и `llama-3.3-70b-versatile`; в чек-листе телефона есть пункт сверить названия и лимиты в AI Studio.
- `queue.ts`: один запрос за раз, не чаще `balance.ai.minGapMs` (5 с), не больше `balance.ai.dailyLimit` (100) в день, на 429 пауза с растущим интервалом (5, 10, 20 с, учитывается retry-after), потом ошибка. Время и сон инъектируются, тесты идут мгновенно.
- `cache.ts`: всё сгенерированное кэшируется в `aiCache` по хешу промпта; там же счётчик запросов дня и маркеры ежедневных работ.
- `prompts.ts`: системная установка (B2, объяснения по-русски одним предложением без терминов, строго JSON), промпты и схемы для `checkProduction`, `sceneTurn`, `freshContexts`, `fromLife` (режимы ru / text / phrase), `mnemonic`, `ping`; валидаторы превращают ответ модели в типизированное значение или `null` (белый список pattern, `ok` не может быть истиной при наличии ошибок).
- `ai.ts`: единственный фасад для игры. Любая задача возвращает `null`, если нет ключа, провайдер отвергнут, пауза после 429 или обрыва сети, офлайн или ответ не по схеме. При `auth` провайдер помечается сломанным и в ход идёт запасной. Дневной лимит выключает ИИ до полуночи. Игра всегда продолжается без него.
- `fake.ts`: детерминированный двойник для dev-панели и Playwright, отвечает по правилам из текста промпта («he work» → sv-agreement, «I can drink» → habit-present-simple, «mistake» → ошибка без pattern, `usedTarget` по вхождению фразы), сцены по счёту ошибок, `fromLife` по первым словам предложений. Ставится хуком `__nemesis.fakeAI()`.
- `daily.ts`: раз в день (маркер в кэше) при открытии лагеря: свежие контексты и ситуация для фраз, которые придут завтра (до 10 одним запросом), досоздание полей у фраз из жизни и исправлений, добавленных без ИИ (до 5), мнемоники немезидам. Новая немезида получает мнемонику и два контекста сразу, в фоне после ответа.

**Приёмы и бой**
- Своя фраза (ступень 4, `moves/ownPhrase`): вопрос про жизнь (`questionEn` из seed или подстановка), печать или микрофон. С ИИ вердикт `checkProduction`: фраза использована → удар, ошибки → удар с опечаткой (Hard) и список исправлений, фраза не использована → промах. Без ИИ: проверка наличия фразы, три образца и честная самооценка.
- Экспромт с ИИ: после местной проверки наличия фразы ответ уходит на `checkProduction`, исправления показываются в фидбеке (`❌ как сказал ✅ как надо`, правило одним предложением, «Естественнее: …», пометка «проверил ИИ»).
- Материализация ошибок (SPEC §8): исправление с `patternId` будит pattern (`reactivatePattern`) и ставит в следующий обычный боевой узел Хамелеона, врага-pattern с Ловушкой прямо в бою (зелёный спрайт, временный элемент `pattern:<id>`, промах не идёт в Эхо и не делает должника). Исправление без pattern становится новой фразой `ai-correction` («вместо «he work»», правило в подсказке, предложение контекстом) и открывает следующий бой тенью. Перевод и остальные поля досоздаёт ежедневная работа.
- Закон 2 цел: ИИ решает только «удар / с опечаткой / промах», оценка FSRS по-прежнему из `grade`.

**Встречи (`game/encounter.ts`, `content/scenes.ts`, экран `/encounter`)**
- Девять сцен из SPEC: арендодатель, паспортный контроль, бар, сериал, рассказ о проекте, кафе, спор, созвон с плохими новостями, собеседование. У каждой вступительная реплика персонажа и три обмена: реплика персонажа после ответа, подсказка по-русски, образец.
- Узел появляется на карте похода (не Вылазки), не больше одного. Сверху чипы с 2–3 фразами, встреченными в этом походе (сначала более продвинутые); фраза в ответе гасит чип и даёт удар ступени 5 (`applyAnswer` приёмом Экспромт). 25 секунд на ответ, тиканье на последних пяти, истёкшее время это пустой ответ.
- С ИИ `sceneTurn` даёт реплику персонажа, проверку последнего ответа и на последнем ходу исход (успех / частично / провал) с причиной. Без ИИ реплики идут по сценарию, после каждого ответа образец и самооценка, исход по числу провалов. Награда по `balance.encounter.runes` (60 / 30 / 10). Исправления показываются после сцены и материализуются.

**«Из жизни» (`/life/:mode`)**
- Не смог сказать: русская мысль → `fromLife('ru')` → карточка с фразой, переводом, предложением и заметкой → в поход. Вставить текст: `fromLife('text')` → до 10 карточек с чекбоксами → добавить выбранные. Вручную: фраза, перевод, пример без ИИ. Входы с ИИ без ключа показаны пунктиром с подсказкой, но открываются.
- Режим чтения: при открытии шторки «В поход» или «Перевод» один запрос `fromLife('phrase')` даёт перевод в этом предложении, второй контекст, ситуации и ложные смыслы; перевод подставляется в поле и правится, при добавлении всё сохраняется.

**Настройки**: ключи Gemini и Groq (поля-пароли с «показать», только IndexedDB), модели, кнопка «Проверить» (живой `ping`), строка статуса «ИИ: gemini · сегодня N из 100» и причина паузы.

**Тесты**: `ai/queue.test.ts` (очередь, лимит, повторы 429), `ai/prompts.test.ts` (валидаторы, промпты, правила двойника), `game/encounter.test.ts` (сцены, чипы, ходы, исход, награда), `e2e/ai.spec.ts` (шесть сценариев на двойнике и один без ИИ).

## Сценарии e2e (`e2e/ai.spec.ts`)

1. **Настройки.** Статус «fake», «Проверить» → «Ответил. ИИ работает.»; ключ, введённый в поле, скрыт точками, переживает перезагрузку, статус становится «gemini»; пустой ключ → «нет ключа». Консоль чистая.
2. **Своя фраза с ИИ.** Принудительный приём; ответ с образцом и «he work» → удар, «проверил ИИ», исправление «he work → he works», pattern sv-agreement активен; в следующем боевом узле Хамелеон с Ловушкой, верный ответ даёт удар.
3. **Встреча с ИИ.** После первого узла один из достижимых узлов превращается в Встречу хуком; чипы есть; фраза из чипа в ответе гасит чип; «mistake» во втором ответе; итог «Частично», +30 рун в походе, исправление «mistake → slip»; в базе элемент `ai-correction` «slip» с контекстом; он открывает следующий бой.
4. **Встреча без ИИ.** Сценарные реплики, образец и самооценка; «Не смог» во втором ответе → «Частично»; к ИИ ни одного обращения.
5. **Из жизни.** «Не смог сказать» → «as a matter of fact», добавлено 1; «Вставить текст» → 5 карточек, одна снята, добавлено 4; «Вручную» 1; читалка подставляет перевод от ИИ и сохраняет ситуации; ежедневная работа на входе в лагерь досоздаёт ситуации ручной фразе.
6. **Немезида.** После провалов фразы в походе в Зале трофеев у неё мнемоника от ИИ и свежие контексты в базе.

Регресс: `smoke`, `run`, `speech`, `progress`, `reading`. Автопилот умеет Свою фразу (с самооценкой без ИИ), Ловушку в бою и Встречу (образец из хука `sceneSample`, самооценка).

`phone-settings-ai` (ключи, модели, «Проверить», статус), `phone-own-phrase-corrections` (крит, «проверил ИИ», ❌ he work ✅ he works с правилом), `phone-chameleon` (зелёный Хамелеон, Ловушка в бою), `phone-scene-start` (сцена, цель, чипы, реплика, подсказка, таймер), `phone-scene-result` (диалог, «Частично», +30, исправления), `phone-scene-self` (без ИИ: образец и самооценка), `phone-life-say`, `phone-life-extract` (карточки с чекбоксами), `phone-reader-ai-draft` (перевод подставлен), `phone-nemesis-mnemonic` (💡 в Зале трофеев), `phone-materialized-enemy`.

Честная оценка: Встреча это первый экран, где игра говорит с тобой, и даже с двойником диалог читается как сцена. Исправления после боя и сцены выглядят как привычный формат ❌/✅. Слабые места: заключительная реплика сценария не зависит от исхода (без ИИ после трёх молчаний персонаж всё равно говорит «Fine, you win»); чипы берутся из встреченных в походе фраз, в первом узле их нет; «Вставить текст» без ИИ бесполезен и честно об этом говорит. Записал в идеи полировки.

## Что нельзя проверить без человека

- [ ] Настоящий ключ Gemini: «Проверить» отвечает, название модели в AI Studio совпадает с `gemini-2.5-flash` (иначе поменять в поле), лимиты бесплатного тарифа не ниже 100 запросов в день.
- [ ] Своя фраза с настоящим ИИ: вердикт разумный, исправления по-русски одним предложением, без терминов; ответ приходит за 2–6 секунд, надпись «Проверяю…» видна.
- [ ] Встреча с настоящим ИИ: реплики персонажа в образе и до 25 слов, исход честный, 25 секунд на ответ голосом хватает.
- [ ] Хамелеон после ошибки с pattern появляется в следующем бою и Ловушка в бою удобна на телефоне.
- [ ] «Не смог сказать» и «Вставить текст» с настоящим ИИ дают естественные фразы, перевод в читалке подставляется за одну-две секунды.
- [ ] На следующий день в лагере: у фраз появились свежие контексты (в Знакомстве и Диктанте новые предложения), у немезиды мнемоника.
- [ ] Ключ Groq как запасной: с пустым Gemini и ключом Groq статус «groq», «Проверить» отвечает.
- [ ] Офлайн: игра идёт без ИИ, ошибок нет, после возврата сети ИИ оживает через минуту.
